# O Barbeiro de Sevilha — Programa Musical Oficial

## Sobre Este Projeto

Este é o **Programa Musical Oficial** da montagem de _"O Barbeiro de Sevilha"_ (_Il Barbiere di Siviglia_) de **Gioachino Rossini**, apresentado pela **Companhia de Ópera Lírico Brasil** em parceria com o **Instituto Antonio Gasparini**, realizado em **Feira de Santana, Bahia, em 9 de maio de 2026**.

O site oferece uma experiência digital interativa e completa sobre a ópera, incluindo:
- Sinopse detalhada da obra e suas árias mais famosas
- Informações sobre a Companhia de Ópera Lírico Brasil
- Histórico e missão do Instituto Antonio Gasparini
- Perfis completos do elenco de solistas e equipe técnica
- Galeria multimídia com fotos e vídeos do espetáculo
- Acesso fácil via QR Code para dispositivos móveis

## Tecnologia

Este é um **site estático** construído com:
- **HTML5** para estrutura semântica
- **CSS3** com design responsivo e moderno
- **JavaScript Vanilla** para interatividade sem dependências externas
- **Compatibilidade:** Funciona em todos os navegadores modernos (Chrome, Firefox, Safari, Edge)

## Recursos Principais

### Design Elegante e Teatral
- Paleta de cores inspirada na estética clássica: tons de vinho, dourado e bege
- Tipografia sofisticada com fontes serif para títulos
- Animações suaves e efeitos parallax

### Navegação Intuitiva
- Menu fixo no topo com links para todas as seções
- Barra de progresso de leitura
- Botão flutuante "Voltar ao topo"
- Navegação por seções: Sinopse, Companhia, Instituto, Elenco, Equipe

### Conteúdo Multimídia
- Galeria de fotos e vídeos integrados
- Foto do elenco em preto e branco de alta qualidade
- Vídeos em formato MP4 otimizados para web

### Responsividade
- Design totalmente responsivo para dispositivos móveis, tablets e desktops
- Otimizado para leitura em qualquer tamanho de tela

### Como Publicar

#### Opção 1: GitHub Pages
```bash
# 1. Criar um repositório no GitHub chamado "barbeiro-sevilha"
# 2. Fazer upload dos arquivos
# 3. Ativar GitHub Pages nas configurações
# 4. O site estará disponível em: https://seu-usuario.github.io/barbeiro-sevilha/
```

#### Opção 2: Netlify
```bash
# 1. Fazer upload da pasta via Netlify Drop (arrastar e soltar)
# 2. Ou conectar um repositório GitHub
# 3. O site receberá um URL permanente
```
